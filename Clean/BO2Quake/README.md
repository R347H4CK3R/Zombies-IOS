# BO2 Quake iOS Clean Rebuild

This directory is the code-only clean rebuild defined by `docs/superpowers/specs/2026-09-13-bo2-quake-clean-rebuild-design.md`.

Retail BO2 content and converted retail payloads are not committed here. The final user-specific self-contained IPA is assembled privately from a user-owned BO2 dump after the completion gate passes.
